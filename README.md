# بالیکا — اعلان ووکامرس در بله

سورس افزونه در `balika/` است. نسخه آزمایشی جاری: **2.5.0-rc.2**؛ برای سایت اصلی تأیید نشده است.

**تغییر امنیتی مهم:** اتصال تلفن‌محور قدیمی به سفارش‌ها دسترسی نمی‌دهد. هر سفارش نیازمند اتصال مجدد با لینک همان سفارش است؛ پیام انبوه و یادآوری سبد مبتنی بر تلفن تا مهاجرت رضایت مخاطب موقتاً بدون مخاطب‌اند. [راهنمای ارتقا و تست RC](docs/RC-2.5.0-rc.2-fa.md).

- **بالیکا ← فروشگاه و کانال‌ها**: ماژول‌های اختیاری فروشگاه React، کاتالوگ ربات و انتشار زمان‌دار؛ [راهنمای نسخه ۲.۴](docs/COMMERCE-2.4-fa.md).
- **بالیکا ← ورود فایل رهگیری**: CSV، تطبیق ستون‌ها، پیش‌نمایش و ثبت تأییدشده؛ [برنامه مرحله‌ای](docs/SHIPPING-PLAN-fa.md).
- **بالیکا ← رهگیری گروهی**: ثبت کدهای رهگیری، انتخاب وضعیت‌های مبدأ و مقصد، صف اعلان مشتری.
- **بالیکا ← مشتریان و پیام‌ها**: مدیریت اتصال، تاریخچه پیام، گزارش CSV، پیش‌نمایش قالب و انتقال تنظیمات.
- راهنمای قابلیت‌ها، ارتقا و تست پذیرش: [نسخه ۲.۳.۰](docs/RELEASE-2.3-fa.md).
- آرشیو قدیمی `balika.zip` حذف شده است؛ فقط بسته نسخه‌دار آزمایشی را برای staging استفاده کنید.

## تست‌ها

```sh
./tests/run.sh
# یا با مسیر دلخواه PHP:
PHP_BIN=/path/to/php ./tests/run.sh
```

تست‌ها جای آزمون واقعی WordPress، WooCommerce، MySQL و API بله را نمی‌گیرند. ابتدا روی سایت آزمایشی نصب کنید.

## ساخت بسته نصب

```sh
python3 scripts/package-rc.py
```

## ساخت و تست رابط مستقل

```sh
npm ci --prefix commerce-ui
npm run build --prefix commerce-ui
npm test --prefix commerce-ui
```

فایل‌های runtime از قبل در `balika/assets/commerce/` هستند؛ سرور سایت به Node نیاز ندارد.
مینی‌اپ رسمی، ورود با هویت بله و پرداخت بومی تا دریافت مستندات رسمی غیرفعال‌اند.

## ممیزی وضعیت فعلی

[گزارش ممیزی تکمیلی](docs/AUDIT-DEEP-fa.md) شامل یافته‌های باز، شواهد بازتولید، اصلاحات تأییدشده و محدودیت آزمون‌هاست. سبزبودن تست‌های عادی به معنی رفع یافته‌های امنیتی باز نیست.

## پشتیبانی انسانی (توسعه‌ای)

**بالیکا ← پشتیبانی انسانی**: صندوق پیام متنی خصوصی بله، ارسال متن مشتری به بله مدیران خصوصی تنظیم‌شده، پاسخ اپراتور از پیشخوان، صف ارسال و بستن گفت‌وگو. پیش‌فرض خاموش است. راه‌اندازی، محدودیت‌ها و ملاحظات حریم خصوصی در [راهنمای پشتیبانی](docs/SUPPORT-fa.md). بله‌پی حذف شده و تنها پاک‌سازی تنظیمات قدیمی آن در ارتقا باقی است؛ درگاه‌های ووکامرس تغییر نمی‌کنند.

روش پیشنهادی پشتیبانی اکنون **ارتباط مستقیم با حساب بله** است: آیدی/لینک در پنل وارد می‌شود و `/support` دکمه چت مستقیم می‌دهد. صندوق قبلی به‌صورت حالت اختیاری باقی مانده است.

در صفحه **رهگیری گروهی**، تیک انتخاب ردیف حذف شده است: فقط ردیف‌های دارای کد که اطلاعاتشان نسبت به زمان بازشدن فرم تغییر کرده ثبت می‌شوند. ردیف خالی و اطلاعات دست‌نخورده نادیده گرفته می‌شوند؛ تأیید جایگزینی کد قبلی حفظ شده است. این تغییر مربوط به ورود دستی است، نه مرحله تأیید فایل CSV.
