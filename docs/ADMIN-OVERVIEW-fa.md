# نمای کلی مدیریت

صفحه پیش‌فرض بالیکا اکنون «نمای کلی» است؛ تب‌های قبلی باقی مانده‌اند و عنوان اتصال به «اتصال بله» تغییر کرده است.

- نمایش نتیجه و زمان آخرین تست دستی اتصال برای توکن فعلی؛ وجود توکن به معنی سلامت اتصال نیست و تغییر توکن نتیجه قبلی را نامعتبر می‌کند. بازکردن داشبورد تماس جدید با بله ایجاد نمی‌کند.
- شمارنده منتظر، ناموفق نهایی و پذیرفته‌شده توسط API از صف موجود؛ این‌ها آمار تمام ارسال‌های مستقیم یا خوانده‌شدن پیام نیستند.
- ثبت زمان شروع واقعی پردازش بعد از دریافت قفل worker؛ زمان شروع با تکمیل موفق تفاوت دارد. زمان اجرای بعدی cron جدا نمایش داده می‌شود.
- هشدار نبود زمان‌بندی یا وجود پیام منتظر بدون شروع پردازش در ۱۵ دقیقه اخیر؛ این هشدار تشخیص قطعی علت خرابی نیست.
- میان‌بر سفارش‌های در حال انجام بدون کد، ثبت رهگیری، ورود فایل و مشتریان/تاریخچه.
- وضعیت حالت پشتیبانی و مقصد مستقیم، همراه با توضیح اینکه مکالمات مستقیم در وردپرس دریافت نمی‌شوند.

این مرحله شامل شمارش سفارش‌های بدون رهگیری، ادغام دو مقصد پشتیبانی، بازچینی کامل منوها یا مرکز سراسری پیام‌ها نیست. هیچ مقصد پشتیبانی قدیمی بازنویسی نشده است. سلامت ذخیره metadata پایش باید در محیط واقعی بررسی شود؛ نبود heartbeat با «خرابی قطعی ارسال» یکی نیست.

اعتبارسنجی: ۳۱۵ بررسی PHP موفق، از جمله ۹ بررسی جدید داشبورد. نحو فایل‌های اصلی تغییرکرده با parser PHP 7.4 بررسی شد. تست‌ها مبتنی بر محیط شبیه‌سازی‌شده‌اند؛ سایت زنده و بله واقعی آزمایش یا به‌روزرسانی نشده‌اند.
