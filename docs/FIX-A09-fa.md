# اصلاح مرحله نهم: تلاش مجدد جزئیات محصول لینک مستقیم (A09)

خطای جزئیات محصول، وضعیت دریافت و شمارنده تلاش مجدد از فهرست محصولات جدا شدند. دکمه تلاش دوباره در پیام خطای جزئیات، همان endpoint و شناسه محصول لینک مستقیم را درخواست می‌کند؛ کاتالوگ را دوباره دریافت نمی‌کند.

- موفقیت درخواست مجدد، جزئیات محصول را باز و خطای همان بخش را پاک می‌کند.
- شکست مجدد، خطای جدید را نشان می‌دهد و دوباره امکان تلاش دارد.
- حین انتظار، دکمه غیرفعال است؛ guard هم‌زمان از دو درخواست ناشی از کلیک‌های سریع جلوگیری می‌کند.
- خطای جزئیات، نمایش کاتالوگ موفق را پنهان نمی‌کند؛ retry کاتالوگ هم خطای جزئیات را پاک نمی‌کند.
- پاسخ درخواست جزئیات لغوشده، محصول یا خطا را تغییر نمی‌دهد.
- بدون productId، درخواست جزئیات ساخته نمی‌شود. same-origin، no-store و nonce درخواست حفظ شده‌اند.

## بررسی

چهار تست تعاملی JSDOM روی bundle واقعی: بازیابی موفق با درخواست فقط همان محصول، شکست تکراری و جلوگیری از کلیک تکراری حین انتظار، خطای هم‌زمان مستقل کاتالوگ/محصول و نبود درخواست جزئیات برای صفحه بدون لینک مستقیم.

ساخت bundle موفق؛ **۱۷ تست JavaScript و ۵۶۷ بررسی PHP موفق**. ممیزی A09 اکنون درخواست مجدد محصول بدون بارگذاری دوباره کاتالوگ را تأیید می‌کند. ممیزی A08 هم موفق است. git diff --check بدون ایراد بود.

فایل اجرایی storefront.js بازسازی شد، اما ZIP قبلی هنوز بازسازی نشده است. مرورگر واقعی موبایل و WordPress/WooCommerce/Bale زنده آزمایش نشده‌اند. تکمیل موارد بازتولیدشده ممیزی به معنی تضمین بی‌نقص‌بودن افزونه نیست؛ به‌خصوص ریسک timeout مبهم شبکه از RC08 همچنان باز است.
