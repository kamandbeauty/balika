## بررسی انجام‌شده

ساخت bundle، ۱۷ تست JavaScript، ۵۶۷ بررسی PHP و runner ممیزی موفق بودند. ۲۴ فایل PHP runtime از نظر نحو PHP 7.4 parse شدند؛ این بررسی جای اجرای runtime روی PHP 7.4 واقعی نیست. تست PHP در WASM و تست رابط در JSDOM انجام شد.

ZIP دوبار ساخته شد و hash یکسان بود. سلامت zip، انطباق بایت‌به‌بایت فایل‌های سورس با آرشیو، نسخه هدر، bundle تازه و تطابق راهنمای داخل بسته با راهنمای بیرونی بررسی شدند. git diff --check نیز بدون ایراد بود. بسته قدیمی RC1 برای شواهد تاریخی باقی مانده و بسته آزمون جاری نیست.

## هنوز انجام نشده

نصب واقعی WordPress/WooCommerce، ارتقای schema در MySQL واقعی، HPOS/CPT، object-cache، بله زنده، مرورگر داخل بله و آزمون هم‌زمانی انجام نشده‌اند. بسته فقط staging است و تأیید تولید ندارد. timeout مبهم شبکه هنوز ریسک تکرار دارد؛ اصلاح checkpoint تضمین exactly-once نیست.

ابتدا بکاپ قابل‌بازیابی تهیه کنید، روی staging با ربات و مقاصد تست جدا نصب کنید و چک‌لیست را تکمیل کنید. ربات/وبهوک تولید را در staging کپی و فعال نکنید. اتصال‌ها و توکن‌های قدیمی فاقد نسخه مالک نیازمند لینک تازه‌اند.
